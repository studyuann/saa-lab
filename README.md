AWS Certified Solutions Architect - Associate (SAA-C03) 전 문항(725문제) 인터랙티브 학습 및 실전 모의고사 웹 플랫폼입니다.

## 🚀 빠른 시작 (실행 방법)

### 1. 원클릭 실행 (Windows)
`run_quiz.bat` 파일을 더블 클릭하면 로컬 웹 서버가 켜지며 기본 브라우저에서 자동으로 열립니다.

### 2. 파이썬 직접 실행
```bash
python app.py
```
브라우저에서 **`http://localhost:5000`** 접속

### 3. 터미널 CLI 퀴즈
```bash
python quiz_cli.py
```

## ✨ 주요 기능

1. **전체 725개 문항 탑재 & 스마트 태그 분류**
   - 658페이지 기출 덤프의 전 문항을 구조화하여 수록
   - 스토리지, 컴퓨팅, 데이터베이스, 네트워크, 보안, 메시징 등 도메인별 자동 분류

2. **학습 네비게이터 & 실시간 검색**
   - `🗺️ 문항 네비게이터`: 725문항 풀이 상태를 색상별(🟢맞음/🔴틀림/⚪미응시/⭐북마크/📝메모)로 확인 및 즉시 이동
   - `🔍 실시간 검색`: 문항 번호(예: `150`) 또는 키워드(`DynamoDB`, `VPC Endpoint` 등) 검색

3. **실전 시험 시뮬레이션 (65문항 모의고사)**
   - 130분 카운트다운 타이머
   - 1000점 만점 환산 스코어링 & 합격(PASS) / 불합격(FAIL) 성적표

4. **개인화 학습 도구**
   - `📝 나만의 메모`: 문제별 오답 분석 및 아키텍처 핵심 메모 작성
   - `🖍️ 단서 키워드 하이라이트`: 시험 정답 단서어 자동 강조
   - `🔀 보기 순서 셔플`: 단순 위치 암기 방지
   - `⭐ 북마크` & `❌ 오답노트` 모아보기

5. **모든 브라우저 및 기기 영구 동기화**
   - `user_progress.json` 로컬 서버 파일 기반 자동 저장으로 크롬, 엣지, 태블릿 등 어디서나 동일한 학습 기록 유지
